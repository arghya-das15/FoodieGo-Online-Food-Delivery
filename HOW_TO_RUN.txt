FOODIEGO 200 — SIMPLE VERSION

1. Extract the ZIP.
2. Double-click RUN_FOODIEGO.bat.
3. Keep the black window open.
4. Open Chrome/Edge.
5. Go to http://localhost:3000
6. Login -> Sign Up -> create your new account.

NO npm install is needed.
